# Guía Rey Calabaza — YorshDMMO

## Publicar en GitHub Pages

Este ZIP es una versión estática lista para publicar: no necesita instalar programas ni configurar un servidor.

1. Descomprime el ZIP.
2. Sube **el contenido de la carpeta**, incluido `index.html`, a la raíz de un repositorio de GitHub.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/(root)`.
5. Guarda los cambios y espera a que GitHub Pages publique el sitio.

No subas la carpeta contenedora del ZIP: GitHub Pages debe encontrar `index.html` en la raíz seleccionada.

## Actualizar la estrategia

El modo admin guarda borradores solo en el navegador donde se editaron. Para compartir una actualización:

1. Abre **Modo admin** y exporta el archivo JSON.
2. En el repositorio, reemplaza `strategy.json` por el archivo exportado.
3. Confirma los cambios en GitHub. GitHub Pages actualizará la guía pública.

La clave del editor es solo un bloqueo visual; cualquier visitante puede encontrarla en los archivos públicos del sitio. No uses esta función para proteger información privada.
